# Football Player Statistics Analysis Using Python

## Project Overview
This project analyzes football player statistics using Python libraries such as Pandas, NumPy, and Matplotlib.

## Features
- Data Cleaning
- Statistical Analysis
- Top Goal Scorers Analysis
- Assist Analysis
- Data Visualization
- Scatter Plots and Histograms

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
